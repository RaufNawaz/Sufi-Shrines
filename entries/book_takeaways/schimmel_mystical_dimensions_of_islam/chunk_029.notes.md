**What this chunk is.** The last thirteen pages of the book: **`INDEX OF SUBJECTS`** throughout, two
columns per page, running from the entry `Dhikr-i jail, jahri, ^alawiya, lisam` on p. 531 to the
entry `Zulf ("tresses"): symbolic meaning of, 300` on p. 543 (pp. 531–543, folios 500–512). There

(tax-exempt endowment)`, `Sajjada-nishln ("successor")`, `Khdnqdh`, `Samac ("mystical concert and

exactly as printed with the PDF page it is printed on.

**THE LOCATOR RULE, APPLIED THROUGHOUT.** Every number inside an index entry is **this book's own
printed folio**, heavily digit-damaged, and **no locator anywhere in this file has been converted
into a `(p. N)`, had 31 added to it, or had a damaged digit resolved inside it.** Where a locator
string is quoted it is quoted **verbatim as printed**, and it is called the book's own index
locator in words. Every page reference given below is the **PDF page the entry is printed on**.
