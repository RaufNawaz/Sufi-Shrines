# rizvi_history_of_sufism_india_1 — chunk 027 — pp. 463–483

**This chunk is the book's Index, end to end: twenty-one pages, two columns a page, alphabetical headwords and printed page numbers and nothing else.** There is no running prose anywhere in pp. 463–483. What follows is therefore a **finding aid**, not a transcription: it records which archive figures and archive place-names the index carries, and the number strings printed against them, so that a future worker can go straight to the right pages of a 491-page book. **Nothing here is a statement about what those pages say — I cannot see them.**

**THE NUMBERS IN THIS CHUNK ARE THE BOOK'S OWN PRINTED PAGE NUMBERS (FOLIOS), NOT PDF PAGE INDICES.** Every number list quoted below is a folio list. **None of them has been converted to a PDF page index and none of them may be read as one.** The conversion for this band (folio = PDF page − 24) applies to *this chunk's own* twenty-one pages, not to the pages the index points at, which lie all across the volume (folios 1–410).

**Alphabetical range covered: from `Bulbul Shah (d. 1326), 290` (p. 463, folio 439) to `Salar Mas‘ud Ghazi, 311-17` (p. 483, folio 459).** The chunk opens mid-B and closes mid-S. **Everything alphabetically before "Bulbul Shah" (all of A, and B down to "Bulbul") and everything after "Salar Mas‘ud Ghazi" (the rest of S, and T–Z) is outside this chunk and was not searched.** That matters for a long list of archive figures — Baba Farid's own main entry, Baha'u'd-Din Zakariyya, Bibi Pak Daman, Bari Imam, Abdullah Shah Ghazi, Bhit/Bhittai, Sachal Sarmast, Shah Hussain, Shah Jamal, Sultan Bahu, Sakhi Sarwar's town, Sehwan, Sial Sharif, Sialkot, Uch, Waris Shah — every one of which sits **outside this chunk's alphabetical range**, not absent from the book.

**The folio regime, and a correction to the run brief.** The brief predicted that index rectos print only the word `Index` with no number, so that recto folios would be unstated. **That is not what the page shows. Every one of the twenty-one pages prints its folio, and I read all twenty-one off the page.** The layout explains the confusion: the running head spans the full page width, so on a **verso** the OCR reads the number first (`440`, then entries, then mid-page `A History of Sufism in India`), while on a **recto** the OCR reads the left column first (headed `Index`), then the Google watermark at the column foot, and only then the number at the head of the right column (`439`). The printed run is unbroken and one-per-page: p. 463 → 439, 464 → 440, 465 → 441, 466 → 442, 467 → 443, 468 → 444, 469 → 445, 470 → 446, 471 → 447, 472 → 448, 473 → 449, 474 → 450, 475 → 451, 476 → 452, 477 → 453, 478 → 454, 479 → 455, 480 → 456, 481 → 457, 482 → 458, 483 → 459. **No page in this chunk is `folio not stated`.**

**Explicit negatives for the shape of these notes.** There is **no narrative, no argument, no quotable sentence, no legend and no miracle anywhere in pp. 463–483 (folios 439–459)** — an index has none of these — so the headings "Legends and miracles (karamat)", "Arguments and interpretations" and "Citable passages" are omitted rather than filled. **"Practices, institutions, economy" is kept, and kept honestly:** the index carries a substantial run of institutional and economic *headwords* (langar, khanqah, jama‘at-khana, sajjada-nashin, madad-i ma‘ash, futuh, jizya, kharaj, dinar, dirham, jital) with their folio lists, and those lists are exactly the finding-aid value a worker on shrine economy needs. **What is recorded there is the headword and its printed number list, never a claim about what the cited pages contain.**

## Doubts

**The source carries no transcriber apparatus — no `[OCR?]`, no `[illegible]`, no `[folio N]` lines — so every inline flag above is mine, on the tesseract route. An index of transliterated names and dense digit-strings is the worst case for this route, and the damage inventory below is long because it is real. No number string above has been repaired; where a string is damaged I have quoted it damaged and said so at the point of use.**

**Mapping doubts**

1. **Every one of the thirty-two bold ids above rests on an index headword and nothing else.** The 18 September 2026 ruling maps a row's principal figure even on an author-only or literary mention, and an index headword is thinner than that: it is a name, a number list, and at best a date. **A consolidator must treat all of these as pointers, not as facts about a shrine.**
2. **Gorakhnath is the principal figure of two rows at once** — `gorakhnath-goraknath-temple` (Gor Khatri, Peshawar) and `tilla-jogian` (Salt Range) — and the index has one undifferentiated entry. **I have given the folio list to both and chosen neither.** The Peshawar site's own name is in the index twice, as "Gorakhtari, 389" and "Gorkhattari, 389" (p. 466, folio 442), which the calibration chunk shows Rizvi locating in Peshawar at that very folio; **under interim convention (a) I have still withheld the id from the bare toponyms, and if that convention reverses they go to `gorakhnath-goraknath-temple`.**
3. **"Jalalu’d-Din Bukhari, see Makhdum Jahaniyan" (p. 470, folio 446) is a collision between two archive rows.** `shrine-of-jalaluddin-surkh-posh-bukhari-jalaluddin-bukhari` carries "Jalaluddin Bukhari" in its own id and name; `shrine-of-makhdoom-jahaniyan-jahangasht` is the man the index sends the reader to. **The index also keeps "Saiyid Jalalu’d-Din Surkh (Bukhari), 203, 277" (p. 483, folio 459) as a separate headword, so the book does distinguish them somewhere — but the cross-reference as printed would send a worker looking for the Surkh-Posh row to the Jahaniyan row's folios. Do not follow it blindly.** A third man, "Jalalu'd-Din Tabrizi, Shaikh, 120, 128, 139, 190, 192, 199, 206, 217, 226, 257 260, 316" (p. 470, folio 446), is in neither row.

21. **Alphabetical order is locally broken in the OCR, which affects the absence findings only where I say so.** For example p. 480 (folio 456) prints "Portuguese / Prince Muhammad, 158, 169, 202-3 / Pramesh, 366 / Pranayama" — *Prince* before *Pramesh*. **I cannot tell from the text whether the disorder is the index's or the column-reading's; where I have reported a name absent I checked the whole letter run on the page rather than relying on strict alphabetical position, but a name displaced across a column break could in principle have been missed.**
