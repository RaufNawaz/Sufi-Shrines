# Allo Mahar

## Verified findings

None. Every lead traced this session either resolved to Wikipedia itself (not citable per the
README — usable only as a pointer to its own citations) or to an underlying source that could
not be fetched. No independently citable, fetchable source confirming any fact about Allo
Mahar Sharif, Pir Syed Muhammad Channan Shah Nuri, or the Naqshbandia Mujadadia Aminia order
was found this session. See Unverified leads below for what Wikipedia claims and why each
underlying citation failed.

Two colonial gazetteers were fetched in full and searched — a negative-but-useful result,
recorded here rather than as an "acquisition lead" since it was actually checked:
- *Gazetteers of the Sialkot District, 1894-95* (Punjab, 1895), full text via archive.org
  (https://archive.org/stream/in.gov.ignca.30716/30716_djvu.txt) — fetched in full (~731 KB of
  OCR text) and searched for "Allo Mahar," "Alu Mahar," "Channan," and "Naqshband"/"Nakshband."
  No matches beyond false positives on "Maharaja" (title, not place name). Accessed 16 August
  2026.
- *Gazetteer of the Sialkot District* (1920 edition), full text via archive.org
  (https://archive.org/stream/in.ernet.dli.2015.105634/2015.105634.Gazetteer-Of-The-Sialkot-District_djvu.txt)
  — fetched in full (~854 KB of OCR text) and searched with the same terms. No matches beyond
  one false positive ("Chanan Chet," an unrelated OCR fragment). Accessed 16 August 2026.

Both are 1890s–1920s OCR scans with visibly degraded text quality in places (e.g. garbled
strings like "*qaolay &lt;1 : dy ae) tae Gat] ean oo*"), so a keyword search is not proof the
gazetteers are silent on this village — a manual page-by-page check of the Daska tehsil
sections would be needed before concluding that. Channan Shah Nuri's dates (1789–1890, per
Wikipedia, unverified) would place him within the 1894-95 gazetteer's living memory if those
dates are correct, which makes the absence somewhat more notable, but this is not confirmed
independently.
