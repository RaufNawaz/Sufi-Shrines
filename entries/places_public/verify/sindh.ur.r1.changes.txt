=== REJECTED ===

V3 #1: شاہ عنات رضوی -> شاہ عنایت رضوی
REASON: Not applied. The English spells this poet 'Shah Inat Rizvi' (d. 1711), and the 'Shah Inayat' later in the file (state journals, para on Sehwan) is a different saint, Shah Inayat (Shaheed) of Jhok, whom the English spells 'Inayat'. V3's premise that they are one person is wrong; merging the spellings would change a name the English spells otherwise. The dictionary has no entry for Shah Inat Rizvi. One spelling per name is kept: عنات for Inat, عنایت for Inayat.

V3 #14: ایک طویل نعت -> ایک طویل مدحیہ نظم
REASON: Fix not applied as written: it drops 'of the Prophet', which the English states ('the verses on whom are read as a long praise of the Prophet'). The sentence was instead made explicit (پیغمبر کی ایک طویل مدح) so it no longer reads as a slip; see the change list.

V3 #47: درد -> خواجہ میر درد
REASON: Fix not applied as written: it gives the name otherwise than the English, which has only 'Dard'. The ambiguity is resolved instead by an appositive (درد اور شاہ عبداللطیف، ان دونوں شاعروں کی راہیں); see the change list.
