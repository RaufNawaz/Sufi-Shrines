REJECTED (or not applied)

R1. V3 issue 4, the added انہیں: the English ("an order was given to mount a camel") leaves the recipient unnamed; the team version has Shaikh Safiuʾd-Din Kaziruni giving the order to someone else. Making the Shaikh the recipient adds an identification the English does not make. The rest of issue 4 (کے بارے میں for منسوب) is applied.
R2. V3 issue 6, the passive تعاقب ... کیا گیا: in Urdu it says Khawas Khan was pursued, which the English does not say. The collocation fault is fixed instead with تعاقب ... جاری رہا, which keeps the English reading.
R3. V3 issue 9, the indicative ہوا تھا: the English says "may have been formally initiated", so the subjunctive ہوا ہو stays (only the extra شاید goes, and وہیں becomes اوچ ہی میں as V3 asks).
R4. V3 issue 10, ایک بزرگ: the English says "a man"; بزرگ adds a saintly or elder standing the English does not give. ایک شخص is used instead, with the semicolon V3 proposes (as Urdu ؛).
R5. V3 issue 17, the zabar form کَچھ مکران: superseded by V2 issue 1 on the same phrase. کیچ مکران removes the "some" reading V3 objects to, and کَچھ would still read as Kutch.
R6. V3 note, مقدس خاندان -> روحانی / بزرگ خاندان: a matter of taste (the English says "holy families"; مقدس is its plain sense). Not applied.
R7. V3 note, حضرت محمد غوث / شاہ محمد غوث: the English keeps the two names apart ("the four sons of Hazrat Muhammad Ghaus ... beside the tomb of Shah Muhammad Ghaus") and does not identify them; making them one man (اپنے والد) would add an identification. Not applied.
R8. V3 note, the unidentified مزار: the English says "the shrine's present caretakers" without naming the shrine; naming one would add a fact. Not applied.
R9. V3 note, ایک دن پہلے with no reference point: the English has "only a day before" in the same way. Not applied.
R10. V3 note, the unnamed وہ in the 40-day quotation: inside a quotation, and V3 itself left it. Not applied.
R11. V3 note, the introduction restating later sections: the English introduction does the same; trimming would drop facts from the Overview. Not applied.
R12. V3 note, ستر میل / چالیس دن in words beside "40 دن" in the quotation: the English has the same split (seventy miles, forty days, and "For 40 days" in the quotation). Not applied.
R13. V3 notes, قصبۂ اوچ and دور دور تک پہنچی: V3 marks both as taste. Not applied.
R14. V2 note, مقامی قصوں for مقامی روایات: V2 offers it only as optional and the hedge is kept; taste. Not applied.
