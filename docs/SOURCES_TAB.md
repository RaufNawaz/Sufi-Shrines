# The Sources tab — `/sources` and `/source/:slug`

*Engineering note, written 17 October 2026 when the tab shipped (`ea10528`). Orientation for the
next session that touches it. Numbers are dated; re-measure rather than quote.*

## What a reader gets

`/sources` is the sixth tab (Rauf asked for "a tab that mentions and visualizes the books and
sources we are using so if someone wants to interact with one of them specifically they can"):

1. **The shelf** — every *work* the archive cites (the hand-curated vocabulary in
   `src/data/source-works.json`, plus read books that are cited), as book spines. Spine width is
   the number of entries resting on the work (square-root scale, 44px floor because a spine is a
   tap target); spine colour is the dominant tradition of those entries, on the pale ground with
   ink text so it holds in the dark theme.
2. **Read in full for the archive** — the 31 books of the OCR book queue with status
   `integrated`, as cards (9 shown, "show all"). Card edge colour is the language the work was
   written in. Status reads *Cited · N entries* or *In review*.
3. **Every source cited** — all 469 distinct citation lines (538 citations, 17 Oct 2026),
   searchable (diacritic- and case-blind), filterable by kind via the coloured bar's legend, sorted
   by most-cited or A–Z, paged 40 then +80. Each row is a native `<details>`: opened, it lists the
   entries citing it, links to the work's page, and to the URL when the citation carries one.

`/source/:slug` (43 pages): kicker, title, author, facts (entries, year, written in / read in,
pages), the note (bilingual), then — when cited — a static dot map beside the tradition mix and a
places tally, the entries, every citation line naming the work, "read alongside it" (what the same
entries also cite, top 6), and **Find a copy**: WorldCat, Google Books, Internet Archive and Open
Library *search* links built from short title + author surname. They are searches, not claimed
holdings, and the page says so (RULE 2).

## Things that are true and not obvious

- **Shrine pages link here now.** Every bibliography line cited by more than one entry carries
  "also cited by N other entries". It linked to `/about#source-…` — a section that renders for
  the **team view only** — so every public reader who followed it landed on nothing. It now links
  to `/sources#source-…`, which clears filters, pages far enough, opens the row, scrolls it to
  centre and marks it with an accent edge.
- **29 of the 31 read books are not cited by any published entry** (17 Oct 2026). Their findings
  are in the pending description/new-row patches. The page is computed from the live sheet on every
  load, so a book lists its entries by itself once a patch that cites it is imported — but its
  `match` string in `reading-library.json` must actually occur in the new citation. Check after any
  import: `sourceLibrary.test.ts` pins the current hits (`{ 'hadiqat-al-awliya': 1 }`) so a change
  is noticed and each new line is read before it is accepted.
- **25 Oct 2026: nine read books had no `match` at all**, so they showed "Read · not yet cited" even
  after the rewritten Descriptions that cite them went live: Tahqiqat-e Chishti, Tarikh-e Lahore,
  Tazkirah Awliya-e Pak o Hind, Khulasat al-Tawarikh, Sufi Lyrics, Bulleh Shah: A Selection, The
  Adventures of Hir and Ranjha, Verses of a Lowly Fakir (and Sawaneh, which no entry cites, correctly).
  Hadiqat's match was `hadiqat al-auliya`, but the rewritten bibliographies spell it *Hadiqat
  al-Awliya*, so it counted 1 entry instead of ~41. Matches added (`hadiqat al-a` for both spellings);
  every line each one catches in `data/import_2026-10-15.csv` was read (one bibliography key each, two
  for Tarikh, Khulasat and Hir and Ranjha, which differ only in the edition note). Measured hits in that
  file: Khulasat 61, Tahqiqat 44, Hadiqat 41, Tarikh 34, Bulleh Shah: A Selection 18, Sufi Lyrics 17,
  Tazkirah Pak o Hind 15, Hir and Ranjha 14, Verses of a Lowly Fakir 13. The pinned test stays
  `{ 'hadiqat-al-awliya': 1 }` on today's built data and must be re-pinned (each line read) at the next
  `data:build` refresh.
- **The kind classifier reads form, not the work.** It looks at italics, quoted titles, URLs,
  periodical names, gazetteers. The page says so beside the filter. The order of the tests *is* the
  classification (see the file's header); the archive's own placeholder rule (`sourceKind.ts`)
  always wins. Distribution on 17 Oct 2026: 143 book, 92 press, 45 record, 34 web, 21 field survey,
  12 article, 11 tradition, 111 general.
- **Book titles stay Latin in the Urdu view** (i18n rule 7: a citation is the reader's search
  string), always inside `<bdi data-latin>`, and never in an attribute — the spine's accessible name
  is visually-hidden text for that reason (`urdu-labels.spec.ts` refuses Latin `aria-label`/`title`).
  A Latin title inside the Urdu page needs its own font and line-height back or it inherits
  Nastaliq's 2.5em line box; `sources.css` does that at the end.
- **The dot map is `aria-hidden`.** An image role around links is nested-interactive (axe), and the
  entries list beneath carries every one of those links once, in reading order.
- **Six tabs is the ceiling.** At 320px each tab is 53px. A seventh destination needs a different
  design, not a seventh tab; `tabs.test.ts` says so.
